# LogistikaBench 🚚

**LogistikaBench** is a specialized evaluation benchmark designed to test the domain knowledge and reasoning capabilities of AI models in logistics, transport, and supply chain management. 

This repository contains the data processing scripts, evaluation harnesses, and the comprehensive dataset (`LogistikaBench1.csv`) used to benchmark model performance across core supply chain disciplines.

## 📊 Dataset Overview

The dataset consists of **1,446** domain-specific multiple-choice evaluation items derived from  academic and professional course materials. The benchmark covers the following core sub-topics:

* **Material Handling:** 696 items
* **Transport:** 404 items
* **Warehousing:** 202 items
* **Supply Chain Management:** 102 items
* **Procurement:** 42 items
